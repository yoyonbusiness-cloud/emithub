# Security Policy

## Supported Versions

Security updates are currently provided for the latest version of EMITHub.

| Version | Supported |
| ------- | --------- |
| Latest  | :white_check_mark: |

Older versions may not receive security updates. Users are encouraged to keep EMITHub up to date.

## Reporting a Vulnerability

If you discover a security vulnerability in EMITHub, please report it privately rather than opening a public GitHub issue.

Please include:

- A clear description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any screenshots, logs, or proof of concept that may help us investigate

Please report security issues through:

**yoyonbusiness@gmail.com**

We will review the report and respond as soon as possible.

Please do not publicly disclose the vulnerability until it has been investigated and, where appropriate, fixed.
