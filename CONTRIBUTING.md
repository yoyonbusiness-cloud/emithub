# Contributing to EMITHub

Thanks for your interest in contributing to EMITHub!

EMITHub is an open-source file sharing platform focused on privacy, simplicity, and fast peer-to-peer transfers. Contributions of all kinds are welcome, whether you're fixing a bug, suggesting an idea, improving the interface, or adding a new feature.

## Ways to Contribute

You can contribute by:

* Reporting bugs
* Suggesting features or improvements
* Improving documentation
* Fixing issues
* Improving performance or reliability
* Improving the UI/UX
* Submitting new features

## Reporting Bugs

Before opening a bug report, please check the existing issues to make sure the problem hasn't already been reported.

When reporting a bug, include as much useful information as possible, such as:

* What happened
* What you expected to happen
* Steps to reproduce the issue
* Browser and browser version
* Operating system
* EMITHub version or commit
* Screenshots or recordings, if applicable

You can use the **Bug Report** issue template when creating an issue.

## Suggesting Features

Feature suggestions are welcome!

When suggesting a feature, explain:

* What the feature would do
* Why it would be useful
* How you think it could work
* Any problems or limitations you think should be considered

Please keep EMITHub's main goals in mind: privacy, simplicity, and useful file sharing.

## Pull Requests

Before submitting a pull request:

1. Make sure your changes are related to the issue or feature you're working on.
2. Test your changes locally.
3. Make sure existing functionality still works.
4. Keep your changes focused rather than combining unrelated changes.
5. Clearly explain what you changed and why.

Pull requests may be reviewed, modified, or declined if they don't fit the direction or goals of EMITHub.

## Code Style

Try to follow the existing structure and style of the project.

Avoid unnecessary changes to unrelated files or code. If you're adding a new feature, keep it as straightforward as possible and avoid adding dependencies unless they're actually needed.

## Development

To work on EMITHub locally:

1. Clone the repository.
2. Install the required dependencies.
3. Configure the required environment variables.
4. Start the development server.
5. Make and test your changes.

Project-specific setup instructions can be found in the repository's README.

## Questions

If you're unsure about something, feel free to open an issue and explain what you're trying to do.

Thanks for helping make EMITHub better! ❤️
